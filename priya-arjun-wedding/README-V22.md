# V22 – Global flower rain restored

After the Open Invitation transition finishes, the original Royal Premium-style pink petal rain is activated across the full viewport using the captured `petal.svg` asset and the original continuous falling/repeat motion pattern (16 petals, 8–15s fall durations, randomized drift/rotation). It remains hidden before the invitation is opened so petals do not run on the entry screen.

The one-time central bloom/particle burst is unchanged.
