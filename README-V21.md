# V21 changes

- Continuous petal rain removed. Petals now burst once during Open Invitation.
- Hero names animate sequentially: first name, second name, then ampersand/date.
- Couple section uses stronger left/right slide + photo/arch stagger based on the captured Royal Premium source.
- Venue section now renders every configured event as animated date/time chips before the venue map and travel notes.
- Live section adds the original-style jali background, animated live dot, and video-camera icon.
- RSVP upgraded to “RSVP & Share” with event selection and WhatsApp share.
- Share upgraded to “Spread The Joy / Share This Invitation” with WhatsApp, Add to Calendar, and Copy Link.
- Scroll-triggered animations are initialized only after the invitation is opened, preventing them from playing invisibly under the entry overlay.
